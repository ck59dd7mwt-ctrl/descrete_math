# Шпаргалка — отношения

## Формулы

| Понятие | Условие |
|---|---|
| рефлексивность | $\forall a\in A:\ a\rho a$ |
| симметричность | $a\rho b\Rightarrow b\rho a$ |
| антисимметричность | $(a\rho b\land b\rho a)\Rightarrow a=b$ |
| транзитивность | $(a\rho b\land b\rho c)\Rightarrow a\rho c$ |
| [[Отношение частичного порядка|частичный порядок]] | рефлексивность + антисимметричность + транзитивность |
| [[Отношение эквивалентности|эквивалентность]] | рефлексивность + симметричность + транзитивность |

## Быстрые ассоциации

- [[Отношение делимости|Делимость]] → частичный порядок.
- Накрытия → [[Диаграмма Хассе]].
- Верхние и нижние вершины → [[Экстремальные элементы]].
- Эквивалентность → [[Класс эквивалентности|классы]].
- Классы не пересекаются и покрывают множество → [[Разбиение множества]].
- Множество классов → [[Фактор-множество]].

## Не перепутать

- Симметричность: связь между $a$ и $b$ автоматически идёт обратно.
- Антисимметричность: связь в обе стороны возможна только при $a=b$.
- Максимальный: выше него никого нет; таких элементов может быть несколько.
- Наибольший: он выше всех; он единственный, если существует.
- На [[Диаграмма Хассе|диаграмме Хассе]] не рисуют петли и транзитивные рёбра.
