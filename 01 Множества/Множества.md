# Множества

Множество — совокупность различных объектов, рассматриваемых как единое целое. Полное объяснение: [[Дискретная математика#2. Множества]].

## Основные обозначения

| Запись | Значение |
|---|---|
| $x\in A$ | $x$ принадлежит $A$ |
| $x\notin A$ | $x$ не принадлежит $A$ |
| $A\subseteq B$ | каждый элемент $A$ входит в $B$ |
| $A=B$ | множества имеют одинаковые элементы |
| $\varnothing$ | множество без элементов |
| $|A|$ | число элементов конечного $A$ |

$$
A=B\iff(A\subseteq B)\land(B\subseteq A).
$$

Порядок элементов и повторы не важны. Пустое множество является подмножеством любого множества.
