# Логические символы

| Символ | Значение |
|---|---|
| $\forall$ | для любого |
| $\exists$ | существует |
| $\Rightarrow$ | влечёт |
| $\iff$ | тогда и только тогда |
| $\neg$ | отрицание |
| $\land$ | и |
| $\lor$ | или |

Объединение множеств связано с «или», пересечение — с «и», дополнение — с отрицанием. Поэтому логика объясняет законы операций и [[Законы де Моргана]].

Полное объяснение: [[Дискретная математика#3. Логические символы]].
